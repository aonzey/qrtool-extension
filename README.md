# QR 划词助手 — 浏览器插件（Chrome / Edge，Manifest V3）

## 功能
1. **划选文字生成二维码**：选中任意页面文字 → 右键 →「生成二维码："..."」，二维码在页面右上角浮层展示（可拖动、可复制原文）。
2. **框选识别页面二维码**：点击工具栏插件图标（或页面右键 →「框选识别页面二维码」），拖动鼠标框选页面上的二维码，自动解码并弹窗显示结果，支持一键复制 / 打开链接。

## 安装（开发者模式加载）
1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录（`qrcode-extension` 文件夹）
4. 建议把插件图标固定到工具栏（拼图图标 → 图钉）

> 提示：如需在本地 `file://` 页面使用，请在扩展详情页打开「允许访问文件网址」。

## 测试
打开本目录下的 `test.html`：
- 划选黄色区域的文字 → 右键生成二维码
- 点击插件图标 → 框选页面上的任意二维码 → 查看识别结果

## 文件结构
```
manifest.json        扩展清单（MV3）
background.js        Service Worker：右键菜单、按需注入脚本、页面截图
content.js           内容脚本：浮层 UI、二维码生成、框选交互、解码逻辑
libs/qrcode.min.js   二维码生成库（qrcode-generator，UTF-8 中文支持）
libs/jsQR.js         二维码解码库（jsQR，支持反色尝试、多尺度）
icons/               扩展图标
```

## 技术说明
- 脚本按需注入，不在所有页面常驻，性能开销小
- 识别基于 `chrome.tabs.captureVisibleTab` 可视区截图 + Canvas 裁剪，对图片二维码、canvas 渲染、跨域图片同样有效
- 解码支持原始 / 2x / 3x 多尺度重试与反色二维码（attemptBoth）
- 划选生成使用 qrcode-generator 自动版本选择，超长文字（>2000 字符截断）会给出提示
- 兼容 Edge（edge://extensions 同样方式加载）
